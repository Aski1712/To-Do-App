# To-Do Task Manager

## 📌 Project Overview
The To-Do Task Manager is a modern, responsive frontend web application
built using HTML, CSS, and JavaScript.
It helps users manage daily tasks efficiently with full CRUD functionality
and persistent storage using browser localStorage.

---

## 🛠️ Technology Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Browser localStorage

---

## ✨ Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or pending
- Filter tasks (All / Completed / Pending)
- Persistent storage using localStorage
- Keyboard accessibility
- Responsive & modern UI

---

## 🧠 How It Works
- Tasks are stored as JavaScript objects
- Each task has a `completed` flag
- Clicking a task toggles its status
- Filters control which tasks are displayed
- All changes are saved to localStorage
- Data persists across browser refresh
